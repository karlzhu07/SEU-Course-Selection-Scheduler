# 东南大学选课预排助手

这是一个单文件 Tampermonkey 用户脚本，用于在东南大学选课网站中维护一张本地预选课表。

## 功能

- 在课程卡片旁注入“+ 预选”按钮。
- 右侧显示第 1 到 13 节、周一至周日的周课表。
- 同时显示节次和具体时间。
- 支持全部、单周、双周和指定周次视图。
- 不同课程使用不同颜色，冲突课程显示红色边框。
- 自动读取页面中已选和已加载的课程数据。
- 提供“已加载课程”后备列表，避免网站 DOM 变化导致无法选课。
- 同一课程选择其他教学班时替换原预选教学班。
- 数据按学期和选课轮次保存在 `localStorage`。
- 不调用正式选课、退课或抢课接口。

## 安装

1. 在 Chrome 中安装 Tampermonkey。
2. 打开 Tampermonkey 管理面板，新建用户脚本。
3. 用本目录中的 `seu-course-planner.user.js` 替换编辑器内容并保存。
4. 登录 `newxk.urp.seu.edu.cn`，进入课程选择页面。

## 使用

先使用网站自身的查询功能加载课程。脚本会尝试拦截课程接口，并在课程卡片旁显示“+ 预选”按钮。若网站页面结构变化，可以展开侧栏底部的“已加载课程”，从列表中加入课程。

预选课表仅用于规划，不代表课程已经正式选中。正式选课、退课和抢课仍由网站或现有脚本处理。

## 开发验证

```bash
node tests/core.test.cjs
node --check seu-course-planner.user.js
```

脚本没有第三方运行时依赖，也没有构建步骤。

## 已知边界

- 登录后的课程接口字段可能随学校系统更新而变化，脚本包含常见字段别名和 DOM 后备解析。
- 如果课程时间无法解析，课程会进入“待处理课程”，不会静默丢弃。
- 自动识别正式已选课程依赖页面或接口中的选中状态；无法识别时仍可正常进行预选规划。
